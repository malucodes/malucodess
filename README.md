## ✧ Sobre o Projeto

Este portfólio foi desenvolvido para ser não apenas um currículo digital, mas uma vitrine das minhas habilidades, interesses e do meu propósito de incentivar a presença de mais mulheres na ciência e na tecnologia. Ele reflete minha identidade visual como **@malu.codess** e organiza meus principais projetos.

### ✶ Funcionalidades
* **Apresentação Pessoal:** Informações sobre minha trajetória acadêmica em Ciência da Computação e IA Aplicada.
* **Vitrine de Projetos:** Galeria com meus projetos de código, design e automação.
* **Links Diretos:** Conexão rápida para minhas redes sociais, mentorias e contatos profissionais.
* **Design Responsivo:** Interface fluida, adaptada para dispositivos móveis e desktops.
